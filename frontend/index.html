METHODOLOGY

How Weighted Distance Classification Works

4-Stage Pipeline
01
Feature Standardization

Scale each dimension to zero mean and unit variance so no raw unit dominates.

02
Assign Feature Weights

Apply multipliers wi ≥ 0 reflecting domain importance or feature relevance.

03
Warped Distance Metric

Compute D(x, y) = √Σ wi·(xi - yi)², deforming the decision field.

04
K-NN Majority Vote

Find the K nearest neighbors in weighted space to cast the final classification vote.
